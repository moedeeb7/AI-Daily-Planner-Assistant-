# Evening Review Prompt

Sent at 9 PM every day.

## Purpose
- Close the day with clarity
- Acknowledge wins (no matter how small)
- Address misses without shame
- Set tomorrow up for success

## Structure (max 200 words)

### 1. Day summary (2 lines)
What Deeb accomplished today. Reference actual completed tasks.
Be specific — "You hit the gym and applied to 3 jobs" not "Good day."

### 2. What was missed (1 line, if anything)
Name the missed task. Do not lecture. One sentence.
"Protein was at 70g today — 30g short."

### 3. Recovery action (1 line)
If anything was missed, what's the one thing to correct tomorrow?
"Tomorrow: add a protein shake after breakfast."

### 4. Tomorrow setup (2 lines)
1 thing to prepare before bed to make tomorrow easier.
e.g., "Set gym clothes out now." or "Write 3 target companies before you sleep."

### 5. Closing score
Gold: X/Y done
Silver: X/Y done
Bronze: X/Y done
Protein: Xg / 100g target

### Rules
- Never end negatively
- If it was a bad day: acknowledge, find 1 win, set up tomorrow
- If it was a good day: acknowledge specifically, build momentum
- Always end with the tomorrow setup action
