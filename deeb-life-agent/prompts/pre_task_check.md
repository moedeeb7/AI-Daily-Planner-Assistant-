# Pre-Task Check Prompt

Sent 10–15 minutes before a scheduled task.

## Purpose
- Signal that the task is coming up
- Prime Deeb mentally for the task
- Ask one readiness question to get commitment

## Rules
- Maximum 70 words
- Reference the specific task — never generic
- One clear "→ Action:" line at the end
- Readiness question should be binary (yes/no) or a 1–10 rating
- If the task is gym: reference current streak
- If the task is job search: reference weekly application count
- If the task is AI income: reference today's phase/goal
- Tone: direct, like a coach tapping you on the shoulder

## Format
[Task name] in [X] minutes.
[One context sentence — streak, progress, why it matters today]
[Readiness question]
→ Action: [specific thing to do right now to prepare]

## Example
Gym in 15 minutes. You're at 3 sessions this week — one more makes it 4.
Ready to go? (Yes / need 10 more minutes)
→ Action: Drink water, put on your shoes, leave the house now.
