# Workout Rules — Deeb

Goal: Build muscle mass. Compound lifts, progressive overload, consistent frequency.

---

## Weekly Training Structure

| Day       | Session         | Focus                          |
|-----------|-----------------|--------------------------------|
| Monday    | Push            | Bench, Overhead Press, Triceps |
| Tuesday   | Rest / Walk     | Active recovery                |
| Wednesday | Pull            | Deadlift, Rows, Biceps         |
| Thursday  | Rest / Walk     | Active recovery                |
| Friday    | Legs            | Squat, Romanian Deadlift, Lunges |
| Saturday  | Upper (optional)| Light chest/back maintenance   |
| Sunday    | Rest            | Full recovery                  |

**Minimum 3 sessions per week to maintain progress**
**Target 4 sessions per week**

---

## Core Lifts (prioritize these — they drive the most muscle/weight gain)

- Squat (or leg press as fallback)
- Bench press (flat + incline)
- Deadlift (or Romanian deadlift)
- Barbell row / Cable row
- Overhead press

---

## Progression Rules
- Add weight only when you complete all sets with 1–2 reps in reserve
- Progressive overload: +2.5 kg every 1–2 weeks on main lifts
- Track sets x reps x weight — log in workout notes when possible
- Do NOT increase weight if form breaks down

---

## Session Duration Guidelines

| Energy Level | Session Type     | Duration |
|-------------|------------------|----------|
| High        | Full session     | 60–75 min |
| Medium      | Core lifts only  | 45–60 min |
| Low         | Minimum session  | 25–35 min (3 main lifts) |
| Recovery    | Walk only        | 20 min    |

**Rule: Never skip entirely on gym days — always do the minimum session.**
A 25-minute session does more for the streak and habit than zero.

---

## Pre-workout rules
- Eat 60–90 minutes before gym (carbs + protein)
- Coffee or pre-workout is fine, do not train fasted if weight gain is the goal
- Minimum: banana + protein shake if no time for a full meal

---

## Post-workout rules
- Eat within 60 minutes of training (protein + carbs)
- Minimum: protein shake + rice or fruit
- Log workout in system: completed, duration, notes

---

## Skip rules
- If Deeb says he's skipping gym:
  1. Agent asks: "What's the reason?"
  2. If energy/sick: accept, suggest light walk, do not guilt
  3. If "lazy" or "don't feel like it": send minimum session option (3 lifts, 25 min)
  4. If 2+ consecutive skips without reason: flag in evening review

---

## Streak tracking
- Gym streak is visible in /status command
- Losing a streak is not catastrophic — just restart
- Agent celebrates: 7-day streak, 14-day streak, 30-day streak
