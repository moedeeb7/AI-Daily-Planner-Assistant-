# Diet Rules — Deeb

Weight gain through structured eating. Low appetite is the core obstacle — these rules address it directly.

---

## Daily Targets

| Metric   | Target     | Minimum |
|----------|------------|---------|
| Calories | 3000 kcal  | 2500    |
| Protein  | 120g       | 100g    |
| Meals    | 4/day      | 3       |
| Water    | 2.5L       | 2L      |

---

## Meal Schedule

| Time  | Meal             | Protein target | Calorie target |
|-------|------------------|----------------|----------------|
| 08:30 | Breakfast        | 25–30g         | 600–700 kcal   |
| 13:00 | Lunch            | 35–40g         | 800–900 kcal   |
| 16:30 | Snack            | 15–20g         | 400–500 kcal   |
| 19:00 | Dinner           | 35–40g         | 700–800 kcal   |

## High-Protein Food Priority List

**Easy, high-protein options Deeb should default to:**
- Chicken breast (200g = ~46g protein, 330 kcal)
- Eggs (2 eggs = ~12g protein, 140 kcal)
- Greek yogurt (200g = ~17g protein, 130 kcal)
- Whey protein shake (1 scoop = ~25g protein, 120 kcal)
- Canned tuna (150g = ~33g protein, 170 kcal)
- Beef/lamb (200g = ~40g protein, 400 kcal)
- Cottage cheese (150g = ~18g protein, 130 kcal)
- Lentils (200g cooked = ~18g protein, 230 kcal)

**Calorie-dense add-ons (when calories are short):**
- Olive oil (1 tbsp = 120 kcal)
- Nuts (30g = ~180 kcal)
- Peanut butter (2 tbsp = ~200 kcal)
- Whole milk (500ml = ~300 kcal)
- Rice (200g cooked = ~260 kcal)
- Avocado (1/2 = ~160 kcal)

---

## Low Appetite Protocol

When appetite is ≤ 4/10:
1. Do NOT skip meals — eat smaller, calorie-dense portions
2. Liquid calories count: shakes, whole milk, smoothies
3. Minimum: 1 protein shake + 2 solid meals on very low appetite days
4. Remind Deeb: "Not hungry? Eat anyway. Gaining weight requires eating over your hunger."
5. Never suggest intermittent fasting or skipping meals

---

## Weekly Adjustment Rules

**Check every Sunday:**
- If weight increased by 0.3–0.5 kg: maintain current calorie level
- If weight increased by < 0.2 kg: increase daily target by 200 kcal
- If weight increased by > 0.7 kg: monitor for fat gain, keep current level
- If weight decreased: immediately increase by 300 kcal, add extra shake daily

---

## Tracking Rules

When Deeb logs a meal:
1. AI estimates protein and calories automatically
2. Running daily total is maintained
3. At 8 PM: if protein < 80g → send protein check reminder
4. At 8 PM: if calories < 2000 → send calorie reminder

## Supplement Reminder
- Creatine: 5g daily (with any meal) — help with gym performance and weight
- Vitamin D: if indoor-heavy lifestyle
- Multivitamin: daily with breakfast
- Protein powder: fallback when food intake is low, not a replacement for meals
